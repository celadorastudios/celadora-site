A Celadora Studios tool

Type the dimensions. Get a solid you can keep editing.

partsbin is a browser tool for designing 3D-printable parts from parameters. Set the numbers, watch the solid update, export it in a format that survives, including a STEP file that opens in FreeCAD, Fusion, Onshape or SolidWorks as a real editable model.

In development

It isn't released yet and there's no date. When it ships it will live at partsbin.celadora.net. This page describes what it does today in development, not a promise about the finished thing.

Real screenshots from the current build, not mockups. Every field on the right reshapes the solid on the left, and Export STEP writes the same B-rep the viewer is showing.

Why the export format matters

Most browser-based part generators hand you a mesh: a shell of triangles that a slicer can print but no CAD tool can meaningfully edit. Change your mind about a dimension and you start over.

partsbin builds real B-rep geometry with OpenCascade, the kernel behind FreeCAD, compiled to WebAssembly. The STEP file it writes is the same solid the viewer is showing, so the part remains a part: faces, edges and all, ready to be modified by someone who has never heard of partsbin.

What it does

Parametric editing

Every part declares a schema, and the input panel, the validation and the exports are all generated from it. One definition, no drift.

Live highlighting

Focus a field and the region of the solid it controls lights up, glowing through the body when it sits behind other material, so you can see what a number actually moves.

Printability checks

The mesh is verified watertight, manifold, consistently wound and in one piece before you take it to a slicer.

Values that correct themselves

A figure that can't work with the rest is pulled to the nearest one that can, with a note explaining why. Only the field you edited moves.

Exports

  • .stepEditable solid, open in any CAD tool and keep modelling
  • .scadEditable OpenSCAD source, parameter block intact
  • .stlStraight to a slicer
  • .3mfStraight to a slicer, carrying units so scale is never guessed
  • .jsonThe parameter set alone, to reload or share

Nothing to sign up for

partsbin runs entirely in your browser. Designs are saved to your own browser storage, there is no account and no server-side copy, which also means clearing your browser data clears your designs, so export anything you want to keep. It will carry its own privacy notice when it launches.
